Guides

Get started

RailwayCross works the moment you open it.

  1. Install for Android or iOS, or use railwaycross.com.
  2. Allow location so the app can find crossings within 20 km.
  3. Pick a crossing from the tray under the big countdown. Tap the countdown itself for detail.
  4. Save it to make it your first screen.

Location off? You will see a prompt instead of a verdict, and trains and timetables still work.

Gate planner

The backend says when trains pass a crossing, but not how long the gate stays down. So the planner assumes each train closes it from 1 minute before to 4 minutes after, and live delays move those windows.

  • Today: gate-down windows and the gaps between them.
  • If you arrive at…: scrub to a time to see the verdict.
  • Busiest hours: a weekly heatmap.

It is computed on your device from the timetable already loaded. Estimates carry a "≈".

API

Public, read-only, no key. The app reads /api/crossings/nearby/, /api/crossings/<id>/timetable/ and /api/trains/live/. Shapes may change.

# crossings within 20 km, with verdicts
curl -G "https://admin.railwaycross.com/api/crossings/nearby/" \
  -d latitude=9.30 -d longitude=76.59 -d radius=20 -d with_status=1

# live trains, sorted by delay (or state / number)
curl "https://admin.railwaycross.com/api/trains/live/?sort=delay"

FAQ

Good questions.

Is it a safety system?

No. It is a planning aid and its data can be wrong. Obey barriers and signals, and always look and listen.

How does it know a train is coming?

Timetables and live running status are combined to work out when each train reaches each crossing, including its delay.

How accurate is the gate-closed time?

Arrival times come from data. How long the gate stays down is an estimate of about 5 minutes per train, which is why the planner shows "≈".

A crossing is missing.

Crossings come from the backend's mapped data. If yours is absent, it has not been mapped yet.

Do I need an account?

No. Saved crossing, theme and alert preferences stay on your device.

What happens to my location?

Your coordinates go with the nearby-crossings request so the server can find crossings within 20 km. There is no account to link them to.

Will it send push alerts?

Settings has closure and delay toggles that record your preference. Push delivery is not live yet.

Does it work offline?

Live data needs a connection. Offline, you get a clear offline state rather than a stale answer.
